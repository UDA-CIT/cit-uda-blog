# Checklist de validation éditoriale

## Qualité analytique
- [ ] La question centrale est explicite et opérationnelle.
- [ ] Le périmètre est défini (pays/région, secteur, période).
- [ ] La logique **Comprendre → Comparer → Expliquer → Projeter → Décider** est respectée.
- [ ] Les conclusions sont actionnables et non spéculatives.

## Données et sources
- [ ] Minimum **2 sources** pertinentes et traçables.
- [ ] Les chiffres sont contextualisés et datés.
- [ ] Les limites et incertitudes sont indiquées.

## Écriture et style
- [ ] Ton neutre, précis, sans marketing.
- [ ] Structure claire (titres, listes, tableaux).
- [ ] « Ce que cela change » est présent et substantiel.

## Gouvernance & versioning
- [ ] L’article est placé dans le bon dossier (drafts/published/archived).
- [ ] Le statut est cohérent avec l’historique (draft → published → archived).
