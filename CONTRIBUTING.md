# Contribuer aux publications CIT

## Objectif
Ce dépôt sert à produire des analyses structurées sur les dynamiques technologiques en Afrique. Les contributions doivent respecter la ligne éditoriale et le guide de style.

## Proposer un article
1. Ouvrir une issue avec le modèle **Article Proposal**.
2. Définir clairement :
   - La question centrale
   - Le périmètre (pays/région, secteur, période)
   - Les sources pressenties (minimum 2)
3. Ajouter les labels pertinents (`draft`, `needs data`, `validated`, `outdated`).

## Rédiger
- Utiliser les templates dans `/templates`.
- Respecter la logique **Comprendre → Comparer → Expliquer → Projeter → Décider**.
- Éviter le langage marketing ou spéculatif.

## Soumettre une Pull Request
La PR doit inclure :
- L’article dans `/articles/drafts`.
- Les sources citées en fin de document.
- La section “Ce que cela change”.
- La checklist de validation complétée.

## Validation
- Minimum 2 sources vérifiables.
- Ton neutre, analytique.
- Conclusions actionnables.

## Publication
- Après validation, déplacer l’article vers `/articles/published`.
- Les contenus obsolètes vont dans `/articles/archived`.
